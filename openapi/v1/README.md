# Export OpenAPI specification

Generates host OpenAPI documents from each API test host (same documents as `/swagger/v1/swagger.json`):

| File | Source | Notes |
|------|--------|--------|
| `hub.openapi.json` | Hub.Api | Auth, users, workspaces, invites, permissions, groups, admin |
| `drive-host.openapi.json` | Drive.Api | Parked assets/scenes/flows/sessions surface |
| `drive.openapi.json` | Hand-written | Target Drive contract; **not** generated by the export script |

## Prerequisites

- .NET 10 SDK

## Usage

From the repository root:

```powershell
.\scripts\export-openapi.ps1
```

The script runs export tests that write `hub.openapi.json` and `drive-host.openapi.json`.

After changing controllers, DTOs, or Swagger filters, re-run the script and commit the updated JSON. Contract tests fail when a committed host file is stale.

## Postman

Regenerate [`Space.Api.postman_collection.json`](../../Space.Api.postman_collection.json) from the Hub spec:

```powershell
.\scripts\export-postman.ps1
```

Set collection variables `baseUrl` and `accessToken` after import. Contract test `PostmanCollectionTests.CommittedPostmanCollection_matchesOpenApiExport` fails when the collection is stale.

## Live document

When a host is running, the same document is served at:

- `/swagger/v1/swagger.json`
- Swagger UI at `/swagger`
